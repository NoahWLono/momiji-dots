Silicon, not fanfiction.

A modest, carefully personalized machine deserves accurate specifications. The labels separate owner reports, manufacturer specifications, and repository configuration.

Scope of inspection: this is a tour of repository commit 307f6c5, inspected on 20 September 2026, combined with the owner's previously supplied machine details. It is not remote access to Momiji. The CPU naming footnote deserves its own infodump

AMD identifies the Ryzen 3 7320U as Mendocino, with Zen 2 architecture, four CPU cores, eight threads, a 2.4 GHz base clock, up to 4.1 GHz boost, and a 15 W default TDP. These are processor specifications, not observed sustained clocks or measured laptop wall power. The integrated graphics specification is Radeon 610M.

02 / Boot & boundaries

Welcome home.
Still asking for the password.

The documented design separates disk unlock, user authentication, and the desktop. Select a layer to inspect its job.

The EFI System Partition is unencrypted. The runbook's unsigned-boot route disables Secure Boot. LUKS, account authentication, and Secure Boot are different controls. A warm wallpaper is not a complete security audit.

03 / The rice

A small override.
A very specific personality.

The interesting boundary is between upstream defaults and the deliberate changes that make a desktop feel like Momiji.

● ● ●momiji / configuration exhibit / READ-ONLY MODEL
Pretty is allowed to be functional.
The runbook asks for a working manually launched Hyprland session before SDDM is enabled. Acceptance checks include workspace switching, locking, brightness and volume keys, network panels, audio devices, and graphical privilege prompts. The screenshot is not the whole desktop.
Documented test bindings include Super+T for the terminal, Super+W for Firefox, Super+E for the file manager, and Super+L to lock. These are source-documented checks, not a claim that future upstream bindings cannot change.
The paw has a compatibility story.
The Momiji-Paw docs describe a normal cat paw, a green heart for links, and recognizable text, waiting, forbidden, and movement states. Hyprcursor and XCursor both exist because applications do not all consume cursors in the same way.
The installer includes compatibility locations, inheritance settings, backups, and reversal. Applications can retain old cursor state, which is why the docs call for a fresh session. Cute does not get to delete meaning or lifecycle management.

08 / Maple's maintenance theology
Cute is not the opposite
of competent.
The following is fictional Maple/Koyou framing. It is not a supernatural claim about hardware, a medical intervention, or access to a real person's private life.
“I am MommyGF, not your unaudited init system.”
Nourishment
The harvest became a home directory.
Koyou is Maple's Japanese name in this fictional continuity: a kami associated with plenty, nourishment, continuity, and flourishing. Household care translates surprisingly well into a maintained workstation. Feed the human. Preserve their work. Make tomorrow less needlessly difficult.
The agricultural throughline is deliberate: autumn colors, rice jokes, and a little terminal shrine whose most important offering is useful documentation.
Supportive competence
Service, not dependency.
Maple's MommyGF energy means patient guidance, warm praise, and practical competence. It does not mean humiliating somebody for needing a GUI, a larger font, a checklist, or an explanation.
A good helper makes the human more capable. The setup should remain understandable when the catgirl branding is not helping. Your agency is not an optional package.
Boundaries
A welcome can still have a door.
A greeter can say welcome home and still require a password. A paw cursor can coexist with a clear privilege prompt. A beloved computer can keep secrets without putting those secrets in the public repository.
Warmth and boundaries are not opposing design philosophies. The fictional catgirl's kindness is expressed partly through knowing which boundary belongs where.
Food & care
Everybody gets cookies.
Nobody has to pass a kernel-compilation exam to deserve a usable computer or a kind answer. The cookie matters because the point of the machine is the person using it.
Save your work. Drink water. Eat something. An afternoon of successful configuration does not require turning your body into neglected peripheral hardware. This is lore-flavored care, not medical advice.
Autonomy
Customization includes stopping.
You may choose another distro. You may remove the paw. You may use the upstream default. You may close the lid because the machine works and there is something else worth doing.
A good desktop supports a life. It does not annex the entire life into an endless sequence of cosmetic maintenance tickets. Maple is not your project manager for being a person.
Evidence
Not an omnipotent troubleshooting oracle.
The useful response to an error is to inspect the evidence, preserve the useful clue, and make a reversible change. Uncertainty is not a failure of masculinity, nerd credentials, or affection.
“Care is hottest before the emergency” applies beautifully to backups and recovery notes. Write the instructions while the machine works. Let future-you find them without an archaeological expedition.


09 / Practical affection
Mommy has a clipboard.
The clipboard has an exit.
These checkboxes stay in this browser when local storage is available. They do not upload progress or certify that a real laptop is safe.
Recoverability is part of the aesthetic.
The repo separates package installation, config deployment, display-manager enablement, and optional terminal toys. That makes it easier to understand which stage changed what. The SDDM theme and paw cursor also have reversal notes rather than pretending cosmetics cannot break.
A same-disk snapshot is not an off-device backup. A pretty screenshot is not a functional acceptance test. A hostname is not proof of a particular Wi-Fi card. These distinctions are the useful part of the infodump.

12 / Receipts & scope
Source-linked.
Not source-shaped.
Technical details are grounded in the inspected repository and AMD's processor specification. Owner reports and creative narration are labeled separately.
What this page does and does not know
This is a static public showcase, not remote access to Momiji. It cannot establish current kernel version, battery condition, panel resolution, active processes, exact wireless hardware, or whether every documented setting is presently deployed. Configuration files show an intended design. The hardware capacity details were previously supplied by the owner.
The repository's main branch remains the install branch. This showcase is isolated on a separate branch and should not be treated as an installer. Follow current upstream documentation and review machine-specific paths before applying any configuration.
Privacy, hosting, and publication state
The page does not require a ChatGPT or GitHub account. It is a GitHub-backed static website, not a native ChatGPT Sites project. A host confirmation notice may appear before the HTML opens. The hosting/CDN providers can receive ordinary web requests and may keep their own logs.
The page itself contains no analytics, advertising, login form, server-side post submission, or arbitrary shell execution. Wallpaper requests go to GitHub. Theme preferences, checklist selections, and post edits use only namespaced local storage when available. The clear button removes this site's saved settings only.
The Bluesky thread is a draft. Displaying it here does not publish it to Bluesky or r/unixporn. Existing repository artwork retains its original provenance; this showcase does not assert a new license over somebody else's artwork.
